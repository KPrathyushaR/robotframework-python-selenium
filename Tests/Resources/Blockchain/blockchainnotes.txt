Blockchain Fundamentals (Most Important)
1. What is Blockchain?
Answer: Blockchain is a distributed ledger that stores data in blocks connected using cryptographic hashes. 
Every participant has a copy of the ledger, making it decentralized, transparent, and tamper-resistant.

Example:
Block 1
 ↓
Block 2
 ↓
Block 3

Every block contains:
Transactions
Previous block hash
Current block hash
Timestamp
Nonce

2. Why Blockchain instead of Database?
Database	Blockchain
Centralized	Decentralized
Editable	Immutable
Single owner	Multiple participants
Fast	Slightly slower
Easy to modify	Cannot modify old records

What is Smart Contract?
A smart contract is a program stored on blockchain.
Example:
