1. What is Blockchain?
Answer: Blockchain is a decentralized digital ledger that stores transactions in linked blocks. 
Every block is connected using cryptographic hashes, making the data secure and difficult to alter.

Example
Imagine a shared Google Sheet that everyone can view, but once a row is added, no one can edit or delete it. Every participant has an identical copy.
Block 1 → Block 2 → Block 3 → Block 4
Interview Tip
"Blockchain is an immutable, decentralized ledger where every transaction is verified by network participants instead of a central authority."

2. Explain a Block.
Answer: A block is a collection of verified transactions. Each block contains:

Transaction data
Previous block hash
Current block hash
Timestamp
Nonce
Example

Transaction:

ABC123

XYZ789

Verify transaction hash.

3. What is Hash?
Answer: A hash is a unique cryptographic fingerprint generated from the block's data.
Even a tiny change in data produces a completely different hash.

Example
Input:
Hello

Hash:
8b1a9953c4611296...

If changed to:
hello

The hash becomes completely different.
Interview Tip

Hash ensures data integrity.

4. What is Mining?
Ans: Mining is the process of validating blockchain transactions and adding new blocks.
Miners solve complex mathematical puzzles and receive rewards.
Example

↓

↓

↓
Miner receives reward
