#### Sorting and Filtering
1.ORDER BY - used to sort the data set in ascending or descending order.
2. LIMIT - used to limit the number of rows returned.
3. DISTINCT - used to return only DISTINCT(unique)
4. LIKE - used to WHERE clause to search for a specific pattern
5. IN - used to specify muliple possible values in a where clauses.
6. BETWEEN - used to filter records within a given range.
7. GROUP BY - used to group records based on requirement.
8. HAVING - used to filter groups.

####

Passsing:- In this process, Query statement is tokenized.
Join:- It is used to combine data from tables based on as common field.
1.INNER JOIN - iot returns the dataset that have matching values in both tables
2. LEFT JOIN - it returns all records from the left table and matched records from the right.
3. RIGHT JOIN - it returns all records from the right table and matched records from the left.
4. FULL JOIN  - it returns all ecords when there is a match in either the left table or right table.

Aggregate Functions:
--------------------
Aggregate functions perform a calucation on a set of values and return a single values.
1.COUNT():-
-returns the number of rows
syntax: SELECT COUNT(*) FROM Employees;

2. SUM():-
- returns the total sum of a numeric column.
syntax:- SELECT SUM(salary) FROM Employees;

3.AVG():-
-returns the average value of a numeric colummn.
syntax:- SELECT AVG(Salary) FROM Employees;

4.MIN():-
- returns the minimum value of a numeric column.
syntax:- SELECT MIN(Salary) FROM Employees;

5.MAX():-
-returns the maximum value of a numeric column
syntax: SELECT MAX(Salary) FROM Employees;
