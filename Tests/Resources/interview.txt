1. Selenium Interview Questions & Answers
Q1. What is Selenium?

Answer:
Selenium is an open-source automation tool used to automate web applications.

Example:

from selenium import webdriver

driver = webdriver.Chrome()
driver.get("https://google.com")
Q2. Components of Selenium?
Selenium IDE
Selenium WebDriver
Selenium Grid
Q3. Difference between Selenium RC and WebDriver?
Selenium RC	WebDriver
Uses Server	Direct Browser Communication
Slow	Fast
Deprecated	Current Tool
Q4. Difference between findElement and findElements?
driver.find_element(By.ID,"user")

Returns single element.

driver.find_elements(By.TAG_NAME,"a")

Returns list of elements.

Q5. Types of Waits?
Implicit Wait
driver.implicitly_wait(10)
Explicit Wait
WebDriverWait(driver,10).until(
EC.visibility_of_element_located((By.ID,"user"))
)
Fluent Wait

Custom polling interval.

Q6. How to handle dropdown?
from selenium.webdriver.support.select import Select

dropdown = Select(driver.find_element(By.ID,"country"))
dropdown.select_by_visible_text("India")
Q7. How to handle alerts?
alert = driver.switch_to.alert
alert.accept()
Q8. How to switch window?
driver.switch_to.window(driver.window_handles[1])
Q9. How to handle frames?
driver.switch_to.frame("frame1")
Q10. Common Locators?
ID
Name
Class Name
Tag Name
Link Text
Partial Link Text
XPath
CSS Selector
2. Robot Framework Interview Questions & Answers
Q1. What is Robot Framework?

Open-source keyword-driven automation framework.

Example:

*** Test Cases ***
Open Google
    Open Browser    https://google.com    chrome
Q2. Sections in Robot Framework?
*** Settings ***
*** Variables ***
*** Test Cases ***
*** Keywords ***
Q3. Difference between Library and Resource?
Library

Imports external libraries.

Library    SeleniumLibrary
Resource

Imports custom keywords.

Resource    CommonKeywords.robot
Q4. How to create custom keyword?
*** Keywords ***
Login To Application
    Input Text    id:user    admin
    Input Text    id:pass    admin123
Q5. How to execute Robot tests?
robot Login.robot
Q6. How to run specific test case?
robot -t "Login Test" Login.robot
Q7. Reports generated?
log.html
report.html
output.xml
Q8. How to pass variables?
robot --variable URL:https://google.com test.robot

6. Agile Interview Questions & Answers

Iterative software development methodology.

Q2. What is Scrum?

Popular Agile framework.

Q3. Scrum Roles?

Q4. What is Sprint?
