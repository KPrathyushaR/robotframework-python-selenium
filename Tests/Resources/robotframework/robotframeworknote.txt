What is Robot Framework?
Robot Framework is an open-source test automation framework that uses keyword-driven testing.

Example:

*** Test Cases ***
Open Google
    Open Browser    https://google.com    chrome
    Close Browser

Instead of writing Python code, you write readable keywords.
Advantages:
- Easy to learn
- Reusable keywords
- Excellent reports
- Supports Selenium
- Supports API testing
- Supports Database testing
================================================================================= 
Installation:-

Install Python:-
---------------
python --version

Install Robot Framework:-
---------------------------
pip install robotframework

Install Selenium Library:-
------------------------------
pip install robotframework-seleniumlibrary

Install Browser Driver:-
--------------------------------
Example:
Chrome
chromedriver.exe

or use Selenium Manager (latest Selenium versions automatically manage drivers).

Verify:-
                robot --version
